# Contributing to Kiosk

Thank you for your interest in contributing to Kiosk.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone git@github.com:YOUR_USERNAME/kiosk.git`
3. Create a feature branch: `git checkout -b feat/your-feature`

## Before Submitting a PR

1. All tests pass
2. Code is properly formatted
3. Commit messages follow conventional commits

## Commit Messages

Use conventional commits:
- `feat:` — new feature
- `fix:` — bug fix
- `test:` — test additions
- `docs:` — documentation
- `refactor:` — code restructuring
- `perf:` — performance improvement
- `chore:` — tooling, CI, etc.

## Intellectual Property

- All code must be original work or MIT-compatible
- Do not copy code from other projects without license verification

## Security

- Report vulnerabilities to security@asymmetric-effort.com
- See SECURITY.md for details
